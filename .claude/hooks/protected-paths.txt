# Paths agents must not edit by hand. Enforced by pre-tool-use.sh for the
# Edit, Write, MultiEdit and NotebookEdit tools, and for Bash commands that
# write to them (redirects, tee, sed -i, cp, mv, rm, ...).
#
# One rule per line: <glob> <reason shown to the agent>
# - A glob without "/" matches the file name at any depth.
# - A glob with "/" matches the path from the repository root; "*" also matches "/"
#   and "**/" also matches no directory.
# - A trailing "/" protects everything below that directory.
# - Matching ignores case. Lines starting with "#" are comments.
