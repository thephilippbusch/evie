# Paths agents must not edit by hand. Enforced by `evie-dev pre-tool-use`
# (tools/evie-dev) for the Edit, Write, MultiEdit and NotebookEdit tools, and
# for Bash commands that write to them (redirects, tee, sed -i, cp, mv, rm, ...).
#
# One rule per line: <glob> <reason shown to the agent>
# - A glob without "/" matches the file name at any depth.
# - A glob with "/" matches the path from the repository root; "*" also matches "/"
#   and "**/" also matches no directory.
# - A trailing "/" protects everything below that directory.
# - Matching ignores case. Lines starting with "#" are comments.

# Release files. release-please writes them when it opens the release PR.

.release-please-manifest.json   The release manifest is owned by release-please, which bumps the versions on release. Register new apps in release-please-config.json instead.
